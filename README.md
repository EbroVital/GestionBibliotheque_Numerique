## A Propos de ce projet

Cette application est une bibliotheque en ligne qui est orienté vers une institution scolaire ( université ou grande ecole ) 
les professeurs ajoutent les livres necessaires pour la formation sur l'application et les etudiants se connectent pour soit le télécharger ou pour le lire en ligne

## Les fonctionnalités
    - ajout 
    - suppression 
    - modification 
    - commenter 
    - telechargement 
    - mettre en favori les documents
